# Grama-Angana

A platform connecting rural workers with customers.

## Features
- Worker registration
- Job posting
- Firebase authentication

## Technologies
- Android Studio
- Firebase
- Java

## Setup
1. Clone repository
2. Open in Android Studio
3. Sync Gradle
4. Run app

## Setup and Run Instructions

### Prerequisites
- Android Studio installed
- Internet connection
- Android SDK installed

### Steps to Run

1. Clone the repository
```bash
git clone https://github.com/Tippareddy/Grama-Angana.git
```

2. Open the project in Android Studio

3. Wait for Gradle Sync to complete

4. Connect Android device or start emulator

5. Click Run ▶ button

6. App will install and launch
